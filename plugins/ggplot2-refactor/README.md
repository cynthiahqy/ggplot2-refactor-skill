# ggplot2-refactor

Claude Code plugin shipping one skill:

- **`refactor-ggplot-helper`** — refactor existing ggplot2 code into a
  transparent, reusable plot helper function using the SEPARATE / EXPOSE /
  DOCUMENT principles. Elicits the design decisions, proposes a signature, and
  applies the refactor only after you approve.

Install:

```
/plugin marketplace add cynthiahqy/ggplot2-refactor-skill
/plugin install ggplot2-refactor@ggplot2-refactor-skill
```

See the [repository README](../../README.md) for other agents and for the
copy-paste install.
